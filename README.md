# s.praise-macropad

A custom 4-key macropad designed for video editing.

## What I made
- Custom PCB designed in KiCad
- 4-key layout using mechanical switches
- XIAO RP2040 controller
- Addressable LEDs
- 3D-printed case designed in Fusion 360

## Firmware
Planned to use KMK firmware once hardware arrives.

## Status
Design complete. Waiting on parts to assemble and test.

## What I learned
- PCB layout and routing
- Case tolerances for 3D printing
- How macropads work electrically
